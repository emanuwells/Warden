
# Contribuir

## Fluxo

1. Criar uma branch dedicada.
2. Fazer alterações pequenas e focadas.
3. Executar as validações de `COMMANDS.md`.
4. Atualizar documentação, estado e changelog quando aplicável.
5. Rever o diff antes de integrar.

## Commits

Usar mensagens claras e imperativas, por exemplo:

- `feat: adicionar endpoint de estado`
- `fix: corrigir validação de datas`
- `docs: atualizar instruções de instalação`
- `chore: atualizar sistema WELLS`

## Pull requests

Incluir objetivo, alterações principais, validações, riscos e rollback.
