# API REST em PHP

- Validar e normalizar input antes da lógica de negócio.
- Usar queries parametrizadas; nunca concatenar input em SQL.
- Separar HTTP, domínio e persistência quando o projeto o permitir.
- Definir content type, códigos de estado e formato de erro consistentes.
- Não devolver stack traces, SQL ou segredos ao cliente.
- Tratar transações, encoding, timezone e nullability explicitamente.
- Adicionar testes de endpoint ou scripts de verificação reproduzíveis.
