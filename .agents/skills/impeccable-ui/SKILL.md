# Impeccable UI — wrapper WELLS

## Processo

1. Carregar uma vez o contexto visual relevante: PRODUCT, DESIGN ou página equivalente.
2. Escolher um único objetivo por passe: layout, tipografia, cor, clareza, polish, onboarding ou hardening.
3. Implementar completamente.
4. Inspecionar desktop e mobile numa ronda agrupada.
5. Corrigir em lote e confirmar no máximo mais uma vez.

## Limites

- Não criar loops de polish abertos.
- Não carregar os 23 comandos upstream; selecionar apenas o modo necessário.
- Não sobrepor a skill de Taste em dashboards ou interfaces multi-step.
