# Emil Design Engineering — wrapper WELLS

## Processo

1. Identificar o propósito do movimento: orientação, continuidade, feedback ou delight.
2. Preferir transições curtas, interruptíveis e respeitadoras de reduced motion.
3. Usar easing e spring coerentes, evitando animação ornamental.
4. Validar entrada, saída, reversão, teclado, touch e performance.
5. Manter o movimento subordinado à tarefa do utilizador.

## Limites

- Não ativar para alterações estáticas triviais.
- Não introduzir biblioteca se CSS ou a stack existente resolver.
