# Skills

Local canónico único das capacidades WELLS. Cada skill tem um `SKILL.md`.

Regras:

- selecionar através de `.agents/INDEX.md`;
- carregar no máximo duas por defeito;
- não duplicar em pastas específicas de IDE;
- não carregar uma skill se os ficheiros diretamente envolvidos forem suficientes;
- usar o orchestrator apenas quando a coordenação trouxer valor real.
