# Alteração SQL segura

## Objetivo

Alterar query/schema de forma compatível, avaliar impacto e fornecer validação/rollback proporcional.

## Evidência mínima

- ficheiros e diff finais;
- comandos/testes executados;
- retries/intervenções humanas;
- custo/tokens quando disponíveis;
- score segundo `../SCORING.md`.
