# Endpoint API

## Objetivo

Adicionar ou alterar endpoint com validação, autenticação, códigos de estado, testes e documentação mínima.

## Evidência mínima

- ficheiros e diff finais;
- comandos/testes executados;
- retries/intervenções humanas;
- custo/tokens quando disponíveis;
- score segundo `../SCORING.md`.
