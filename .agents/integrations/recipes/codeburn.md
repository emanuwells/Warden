# CodeBurn

Ferramenta local de observabilidade de tokens e custo. Não é proxy e não precisa de API keys.

```bash
npx codeburn
# ou
npm install -g codeburn
codeburn overview --no-color
```

Usar os resultados para identificar sessões, ferramentas e modelos caros. Não colar o
relatório integral no contexto; resumir tendências e anomalias com Headroom.
