# Packs oficiais Anthropic

No Claude Code:

```text
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills
```

Instalar apenas packs utilizados. As skills documentais mantêm licenças próprias e não
são redistribuídas pelo WELLS. O `/code-review` está incluído nas versões atuais do
Claude Code; confirmar disponibilidade antes de adicionar alternativas.
