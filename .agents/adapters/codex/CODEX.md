# Codex

Modo universal:

```text
Lê .agents/AGENTS.md e <tarefa>.
```

`configure --agent codex --apply` pode adicionar uma regra curta ao perfil do
utilizador. Não é necessário criar `.codex/` no projeto.

Modelo/provider: seguir `.agents/core/MODEL_ROUTING.md`; o adapter não fixa modelos concretos.
