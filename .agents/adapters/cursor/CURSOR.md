# Cursor

Usa o caminho explícito para manter o comportamento independente de versões e
configurações do editor:

```text
Lê .agents/AGENTS.md e <tarefa>.
```

Opcionalmente, copia `.agents/setup/CURSOR_USER_RULE.txt` para as User Rules.
Não é necessário versionar `.cursor/` no projeto.

Modelo/provider: seguir `.agents/core/MODEL_ROUTING.md`; o adapter não fixa modelos concretos.
