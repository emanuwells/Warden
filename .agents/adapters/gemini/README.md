# Gemini CLI

O modo universal não exige configuração específica:

```text
Lê .agents/AGENTS.md e <tarefa>.
```

Opcionalmente, `configure --agent gemini --apply` instala uma regra curta no
perfil do utilizador, sem criar `GEMINI.md` ou `.gemini/` no projeto.

Modelo/provider: seguir `.agents/core/MODEL_ROUTING.md`; o adapter não fixa modelos concretos.
