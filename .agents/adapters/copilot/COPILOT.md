# GitHub Copilot

Em superfícies com acesso ao repositório, usa:

```text
Lê .agents/AGENTS.md e <tarefa>.
```

Só criar instruções específicas em `.github/` quando existir uma necessidade
exclusiva do Copilot que não possa ser expressa no runtime universal.

Modelo/provider: seguir `.agents/core/MODEL_ROUTING.md`; o adapter não fixa modelos concretos.
