# .agents

Pasta interna com regras, operação e Skills para IAs.

## Estrutura

```text
.agents/
├── policies/
├── ops/
├── mcp/
├── templates/
└── skills/
```

- `policies/`: regras transversais.
- `ops/`: runbook, quality gates, handoff e estrutura.
- `mcp/`: política, exemplos e templates seguros de MCP.
- `templates/`: modelos genéricos para novos projetos.
- `skills/`: procedimentos específicos ativados quando relevantes.
